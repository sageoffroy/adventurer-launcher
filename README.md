# Adventurer Launcher

Launcher de Windows para **Aventureros de Azeroth**.

La primera versión tendrá un alcance deliberadamente chico:

- Noticias.
- Changelog.
- Selección y validación de la carpeta de World of Warcraft 3.3.5a.
- Actualización de los dos parches del cliente.
- Lanzamiento de `Wow.exe`.

El desarrollo activo se realiza en ramas `feature/*` antes de integrar a `main`.
